# Solo is a private application. It is not intended for public search
# indexing, AI/LLM training, or inclusion in AI answer engines.
#
# Design of this file:
#  * Major search engines are ALLOWED to fetch, on purpose. Every response
#    carries `X-Robots-Tag: noindex` (Solo.Api/SecurityHeaders.cs); a crawler
#    has to be able to fetch a URL to see that header and drop it from the
#    index. A blanket Disallow would instead leave a bare-URL listing they
#    never fetch and so never learn is noindex.
#  * AI/LLM crawlers honour Disallow but ignore noindex, so they are blocked
#    from crawling outright.
#  * Everything else is blocked by the wildcard.
#
# robots.txt is advisory. Crawlers that ignore it are handled at the edge
# (Cloudflare "Block AI bots" / Bot Fight Mode) and by the app's own SSO gate.
